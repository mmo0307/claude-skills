# claude-skills

Коллекция скиллов для Claude Code, разложенная по категориям (60 скиллов).

## 🎨 Дизайн и UI/UX — `design/`
| Скилл | Для чего |
|---|---|
| **frontend-design** | Помогает сделать интерфейс с узнаваемым визуальным стилем, а не шаблонным: направление, типографика, выбор решений. |
| **ui-ux-pro-max** | Большая база знаний по UI/UX для web, mobile и desktop: 79 стилей, палитры, шрифтовые пары, UX-гайдлайны, иконки, типы графиков, 22 стека. Подходит для проектирования, ревью и исправления интерфейсов, доступности и адаптива. |
| **design-dna** | Разбирает референсы (скриншоты, URL) в JSON-профиль: токены дизайн-системы, стиль и визуальные эффекты. Потом по этому профилю можно сгенерировать дизайн. |
| **canvas-design** | Создаёт статичные постеры и арт в PNG/PDF. |
| **algorithmic-art** | Генеративное искусство на p5.js: flow fields, частицы, seeded-рандом, интерактивные параметры. |

## 🔧 Рабочий процесс (`workflow/`)

### Планирование и интервью
| Скилл | Для чего |
|---|---|
| **grill-me** | Запускает безжалостное интервью, чтобы довести план или дизайн до ясности. Вызывается вручную и делегирует скиллу `grilling`. |
| **grill-with-docs** | То же интервью, но по ходу работы ведётся документация: ADR и глоссарий (`grilling` + `domain-modeling`). |
| **grilling** | Основа интервью: дерево решений, вопросы раундами, к каждому вопросу рекомендуемый ответ. Сессия заканчивается, когда не осталось неразобранных веток. |
| **wayfinder** | Планирование работы, которая не помещается в одну сессию агента: карта из тикетов-решений в трекере, которые закрываются по одному, пока путь к цели не станет ясен. |
| **to-questionnaire** | Превращает вопрос, на который нельзя ответить самому, в Markdown-опросник для другого человека. |
| **wait-what** | Аварийная кнопка: «последнее сообщение не дошло». Агент переобъясняет простым языком с нужным контекстом и терминами из `CONTEXT.md`. |

### Спеки и тикеты
| Скилл | Для чего |
|---|---|
| **to-spec** | Без интервью превращает текущий разговор в спецификацию и публикует её в трекер задач. |
| **to-tickets** | Режет план или спеку на тикеты-вертикальные срезы (tracer bullets) с зависимостями и публикует их в трекер. |
| **triage** | Проводит issues и внешние PR через состояния триажа: категоризация, проверка, интервью, агентский бриф. |
| **implement** | Реализует работу по спеке или тикетам: TDD, проверка типов и тестов, ревью и коммит в текущую ветку. |

### Код и качество
| Скилл | Для чего |
|---|---|
| **tdd** | Разработка через тестирование (red → green): что такое хороший тест, где ставить швы, антипаттерны и правила цикла. |
| **diagnosing-bugs** | Дисциплина поиска сложных багов и регрессий производительности: сначала петля обратной связи, затем гипотезы, инструментация, исправление и очистка. |
| **code-review** | Ревью диффа по двум осям параллельными субагентами: соответствие стандартам репозитория и соответствие спеке. |
| **resolving-merge-conflicts** | Решает конфликты merge/rebase: поиск первоисточников изменений, разбор каждого хунка, прогон проверок, завершение. |

### Архитектура и домен
| Скилл | Для чего |
|---|---|
| **codebase-design** | Общий словарь для проектирования глубоких модулей: модуль, интерфейс, шов, адаптер, рычаг (leverage), локальность. |
| **improve-codebase-architecture** | Ищет возможности углубления модулей, показывает их в виде HTML-отчёта, затем разбирает выбранный вариант интервью. |
| **domain-modeling** | Строит и уточняет доменную модель: глоссарий `CONTEXT.md` и ADR по мере появления решений. |
| **prototype** | Одноразовый прототип для ответа на дизайн-вопрос: HTML-демо для логики или несколько вариантов UI на одном маршруте. |

### Работа с агентами
| Скилл | Для чего |
|---|---|
| **handoff** | Сжимает текущий разговор в документ передачи, чтобы свежий агент продолжил работу. |
| **research** | Фоновый агент изучает вопрос по первоисточникам и сохраняет выводы в Markdown-файл в репозитории. |
| **writing-for-agents** | Справочник по написанию документов для агентов: скиллы, `AGENTS.md`, `CLAUDE.md`, указатели контекста, иерархия информации. |
| **wizard** | Генерирует интерактивный bash-мастер, который проводит человека по шагам, доступным только ему (ключи, секреты CI, миграции). |
| **teach** | Многосессионное обучение теме в отдельной рабочей папке: миссия, уроки, справочники, записи об освоенном. |
