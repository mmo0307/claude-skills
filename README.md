# claude-skills

Коллекция скиллов для Claude Code, разложенная по категориям (37 скиллов).

## 🎨 Дизайн и UI/UX — `design/`
| Скилл | Для чего |
|---|---|
| **frontend-design** | Помогает сделать интерфейс с узнаваемым визуальным стилем, а не шаблонным: направление, типографика, выбор решений. |
| **ui-ux-pro-max** | Большая база знаний по UI/UX для web, mobile и desktop: 79 стилей, палитры, шрифтовые пары, UX-гайдлайны, иконки, типы графиков, 22 стека. Подходит для проектирования, ревью и исправления интерфейсов, доступности и адаптива. |
| **design-dna** | Разбирает референсы (скриншоты, URL) в JSON-профиль: токены дизайн-системы, стиль и визуальные эффекты. Потом по этому профилю можно сгенерировать дизайн. |
| **canvas-design** | Создаёт статичные постеры и арт в PNG/PDF. |
| **algorithmic-art** | Генеративное искусство на p5.js: flow fields, частицы, seeded-рандом, интерактивные параметры. |

## 🎬 Анимация и motion — `animation/`
| Скилл | Для чего |
|---|---|
| **motion-design** | Принципы motion-дизайна: тайминг, easing, хореография, принципы Диснея для UI, микроинтеракции, переходы. Работает с CSS, Framer Motion, GSAP, Lottie. |
| **motion-principles** | Базовая версия: тайминг, easing, enter/exit-паттерны, доступность, производительность. |
| **gsap-core** | Основной API GSAP: `to/from/fromTo`, easing, stagger, `matchMedia` (адаптив и reduced-motion). |
| **gsap-timeline** | Таймлайны: последовательности анимаций, position-параметр, вложенность. |
| **gsap-scrolltrigger** | Анимации по скроллу: pin, scrub, параллакс. |
| **gsap-plugins** | Плагины GSAP: Flip, Draggable, SplitText, ScrollSmoother, SVG-плагины, CustomEase и др. |
| **gsap-react** | GSAP в React/Next.js: хук `useGSAP`, `gsap.context()`, очистка при unmount. |
| **gsap-frameworks** | GSAP в Vue, Nuxt, Svelte, SvelteKit: жизненный цикл, scope, cleanup. |
| **gsap-utils** | Хелперы `gsap.utils`: clamp, mapRange, snap, random, wrap, pipe и др. |
| **gsap-performance** | Оптимизация анимаций: transforms, will-change, батчинг, борьба с лагами и 60fps. |
| **slack-gif-creator** | Анимированные GIF, оптимизированные под лимиты Slack. |
