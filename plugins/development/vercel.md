# vercel

- **Источник:** `claude-plugins-official` (Vercel), версия 0.44.0, лицензия Apache-2.0, https://github.com/vercel/vercel-plugin
- **Установка:** `claude plugin install vercel@claude-plugins-official`
- **Для чего:** сборка и деплой веб-приложений и агентов. Скиллы по Next.js, AI SDK, функциям, хранилищам, окружениям, CI/CD, shadcn, Turbopack и командам `/vercel:deploy`, `/vercel:env`, `/vercel:status`.
