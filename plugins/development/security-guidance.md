# security-guidance

- **Источник:** `claude-plugins-official` (Anthropic), версия 2.0.16
- **Установка:** `claude plugin install security-guidance@claude-plugins-official`
- **Для чего:** проверка безопасности кода, который пишет Claude. Предупреждения по шаблонам при правках, LLM-ревью диффа при остановке и агент-ревьюер коммитов (инъекции, XSS, SSRF, захардкоженные секреты и ещё 25+ классов уязвимостей).
