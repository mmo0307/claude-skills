# claude-code-setup

- **Источник:** `claude-plugins-official` (Anthropic), версия 1.0.0
- **Установка:** `claude plugin install claude-code-setup@claude-plugins-official`
- **Для чего:** анализирует кодовую базу и рекомендует автоматизации для Claude Code: хуки, скиллы, MCP-серверы, сабагенты. Даёт скилл `claude-automation-recommender`.
