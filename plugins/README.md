# Плагины Claude Code

Список плагинов, которые у меня установлены, по категориям. Здесь только описания и команды установки. Исходный код плагинов не копируется: у каждого свой автор и своя лицензия, ставятся они из своих маркетплейсов.

Плагины из `claude-plugins-official` ставятся командой `claude plugin install <имя>@claude-plugins-official`. Плагины маркетплейса `knowledge-work-plugins` подключаются через меню `/plugin`.
